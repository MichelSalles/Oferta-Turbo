# Oferta Turbo — MVP 1.0

Aplicação web mobile-first para gerar mensagens de promoções com link de afiliado Amazon.

## Como publicar pelo celular

Opção simples:
1. Crie um repositório no GitHub pelo navegador.
2. Envie `index.html` e `manifest.json`.
3. Importe o repositório em um serviço de hospedagem estática, como Vercel, Netlify ou Cloudflare Pages.
4. Abra o link publicado no Safari e use “Adicionar à Tela de Início”.

## O que já faz
- Gera texto pronto para WhatsApp.
- Calcula desconto automaticamente quando há preço anterior.
- Inclui cupom, categoria e observação.
- Compartilha via WhatsApp.
- Salva as últimas ofertas no navegador do aparelho.
- Inclui aviso de afiliado Amazon.
